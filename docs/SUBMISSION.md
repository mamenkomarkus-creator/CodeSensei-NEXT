## Демо на захисті (3–5 хв)

1. Відкрити `/health`, дочекатися `status: running`.
2. У VRChat: Allow Untrusted URLs.
3. Пресет 1–24 → текст на терміналі.
4. Код-рев’ю → 5 символів → `/paste` → відповідь ментора.
