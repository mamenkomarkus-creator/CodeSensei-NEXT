# NEXT presentation

Official Erasmus+ NEXT Student Creative Project Competition template, filled as PDF so it opens in Preview, Acrobat, and PowerPoint.

| File | Language |
| --- | --- |
| [CodeSensei-NEXT-UK.pdf](CodeSensei-NEXT-UK.pdf) | Українська |
| [CodeSensei-NEXT-EN.pdf](CodeSensei-NEXT-EN.pdf) | English |

Laboratory screenshots used on the slides: `lab/` (MacPaw AI Lab / MetaLab classroom model).

Rebuild (macOS, Arial, Node):

```bash
cp /path/to/official/template.pdf docs/presentation/_next-template.pdf
node scripts/build-next-pdf.mjs both
```
